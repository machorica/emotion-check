# 우리반 감정 기록 웹앱

학생들이 자신의 감정을 기록하고, 반 친구들의 감정 상태를 함께 살펴볼 수 있는 학급용 감정 기록 웹앱입니다.

## 실행 링크

아래 링크에서 웹앱을 실행할 수 있습니다.

https://script.google.com/macros/s/본인웹앱주소/exec

## 주요 기능

- 학생 이름 입력
- 오늘의 표정 선택
- 감정 태그 복수 선택
- 에너지 레벨 기록
- 친구들의 감정 기록 확인
- Google Spreadsheet에 데이터 자동 저장
- Google Apps Script를 활용한 데이터 저장 및 조회

## 사용 기술

- HTML
- Tailwind CSS
- JavaScript
- Google Apps Script
- Google Spreadsheet

## 파일 구성

- `index.html` : 웹앱 화면 및 프론트엔드 코드
- `Code.gs` : Google Apps Script 백엔드 코드
- `README.md` : 프로젝트 설명 문서

## 활용 목적

학급 학생들이 자신의 감정을 간단히 표현하고, 친구들의 감정 상태를 살펴보며 서로를 이해하는 학급 문화를 만들기 위해 제작했습니다.
